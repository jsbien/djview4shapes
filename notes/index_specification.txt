To the basename of the file opened by djview-shapes refer here as <basename>.

Besides the debug output, e.g.

Running djview with: djview "file:///home/jsbien/git/tmp/downloads/Augezdecki.djvu?djvuopts=&page=41&highlight=597,1352,10,25"

a line should be appended to the semicolon separated spreadsheet named
<basename>.csv (created if not exists) located in the current
directory in the following format

1. size and dimensions of the highlighted area
2. the argument of djview
3. timestamp
4 a single character `※` (U+203B REFERENCE MARK)
